Возможности

Всё важное для общения

ArturChat развивается постепенно. В текущей версии доступны основные инструменты для повседневного общения.

✉

Чаты в реальном времени

Отправляйте и получайте текстовые сообщения через интернет. Новые сообщения появляются в открытом чате без повторного входа.

✓✓

Статусы сообщений

Понимайте, отправлено ли сообщение, доставлено ли оно собеседнику и прочитано ли.

◉

Непрочитанные сообщения

Счётчики непрочитанных и предварительный просмотр последнего входящего сообщения помогают не пропустить важное.

♫

Голосовые звонки 1:1

Звоните собеседнику прямо из чата. Для передачи голоса используется интернет-соединение между устройствами.

↻

Обновление внутри приложения

ArturChat проверяет новые релизы, скачивает APK и проверяет его контрольную сумму перед установкой.

⌁
