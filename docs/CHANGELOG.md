# История изменений ArturChat

## [0.5.3] — 3 ноября 2026

- Добавлен полноценный экран личного профиля с загрузкой данных текущего пользователя из Supabase.
- Реализовано редактирование имени и уникального псевдонима с проверкой формата и обработкой занятого имени.
- Изменения профиля сохраняются только для текущего авторизованного пользователя с соблюдением существующих RLS-политик.


Здесь публикуются изменения официальных версий приложения. Список релизов на сайте синхронизируется с GitHub Releases.

## [0.5.2] — 3 ноября 2026

- Обновлено окно сообщения о новой версии: теперь в нём отображаются номер версии, адрес официального сайта и информация о команде.
- Официальные релизы публикуются в GitHub Releases. Приложение проверяет наличие новой версии, загружает подписанный APK и проверяет его SHA-256 перед установкой.
- В текущую версию включены улучшения чатов: мгновенное отображение отправленного сообщения без повторного входа в чат, правильный порядок сообщений и время отправки.
- Добавлены статусы «Отправлено», «Доставлено» и «Прочитано», счётчики непрочитанных сообщений и предварительный просмотр последнего непрочитанного входящего сообщения.

## [0.4.7] — 31 октября 2026

- Опубликован подписанный APK приложения и файл с контрольной суммой SHA-256.
- Подробности этого выпуска и его состав доступны на странице релиза GitHub.
